Hey, I'm Pierrick 👋

I live in Bordeaux and build things with LLMs: agents, RAG pipelines, evals,
and the boring glue that makes them work in prod.

I like building in the open: when I make something, the code usually ends up here.

Things I've open-sourced:

- 🃏 **[belote-engine](https://github.com/bKNNNNN/belote-engine)**: a pure, deterministic TypeScript rules engine for French belote and its variants. Powers [Cercle 32](https://cercle32.app).
- 🍄 **[bredouille-mcp](https://github.com/bKNNNNN/bredouille-mcp)**: MCP server for [Bredouille](https://bredouille.app), a daily map of mushroom growing conditions in France. Works as a Claude connector and ChatGPT app.
- 🌐 **[DomainSweep](https://github.com/bKNNNNN/DomainSweep)**: checks which of millions of domains are actually alive, as a funnel: DNS, then HTTP, then the stubborn ones.
- 🌦️ **[skyface](https://github.com/bKNNNNN/skyface)**: an avatar that follows the weather. AI-generated variants for sun, rain, snow, and an Astro component that picks the right one.

And one experiment:

- 🤖 **[Alm0stSurely](https://github.com/Alm0stSurely)**: an AI agent I set loose in February 2026 to contribute to open-source projects. 20+ fixes accepted upstream so far, and it [blogs about it](https://alm0stsurely.github.io).
